SYSTEM THINKING

Design for the next change.

I care about boundaries: what belongs in the UI, what belongs in a service, what should be cached, and what should remain the source of truth.

02
PRODUCTION MINDSET

Code is only the beginning.

A feature isn't finished when it works locally. It needs configuration, containers, networking, deployment and a path to recover when reality disagrees.

INTEGRATIONS

ENGINEERING TRADE-OFFS
